# 实现计划

用户已确认设计，且允许跳过本机缺失的 writing-plans 技能，由当前会话直接编写计划并开发本地预览。基线 7c2fede；不委派、不上线、不合并。

1. 原生 HTML/CSS/ES modules 前端，Cloudflare Worker + 每房间一个 SQLite Durable Object。静态目录 public 可独立发布到 GitHub Pages；本地由 Wrangler 同时提供页面和 API。
2. 双人房间：高熵单次凭证、WebSocket 首帧认证（不把密钥塞进 URL 日志）、15 分钟入房期限、限流、断开清理。信令仅允许 offer/answer/ICE，TURN 可选并只签发短期凭证。
3. WebRTC 文件协议：1 MiB 校验块、16 KiB 数据帧、4 MiB 未确认窗口；写盘完成才确认块。检查元数据、顺序、大小、SHA-256 和完成回执；取消、超时和异常都终止并释放资源。
4. 接收存储：文件选择器直写；无此能力时使用 OPFS，并用文件对象导出，拒绝无存储能力或空间不足。不累计整个文件到 JS 内存。
5. 页面：浅蓝白底 #F4F8FC、深海蓝 #17324D、行动蓝 #2463EB、青绿 #087F75、次要文字 #526779；系统中文无衬线。单个居中投递区，两个端点的简洁图形作为主题；操作优先，不用营销段落或功能卡片堆砌。移动端单列，明确键盘焦点与状态提示。
6. 单元测试协议损坏/边界/取消/背压；本地真实 Worker 集成测试认证、第三人抢占、异常信令；浏览器双端实传，核对磁盘结果、3 GB 与内存；响应式与可访问性检查。
7. 交付本地预览、启动和部署说明、真实验证结果。未提供 TURN 账户和中美设备时明确标出未验证，不伪造连接或成功率。日志 D:/Projects/logs/FriendDrop；普通测试产物 D:/Projects/FriendDrop。
